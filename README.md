# DVLD System

A desktop application for managing driving license services and applications.

## Technologies Used

* C#
* .NET Framework
* Windows Forms
* SQL Server

## Features

* Manage people records
* Manage drivers
* Create local driving license applications
* Schedule vision and written tests
* Issue driving licenses
* Renew licenses
* Replace lost or damaged licenses
* Detain and release licenses
* Manage application types and test types
* User management and permissions system

## Database

The database script is included inside the `Database` folder.

## Screenshots

Screenshots of the system are available inside the `Screenshots` folder.

## How to Run

1. Restore the database using the SQL script.
2. Open the solution file in Visual Studio.
3. Update the database connection string if needed.
4. Run the project.
